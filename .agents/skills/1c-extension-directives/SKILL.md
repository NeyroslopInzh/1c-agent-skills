# Директивы расширения

Чужую процедуру расширяют только `&Перед`, `&После` и `&ИзменениеИКонтроль`. `&Вместо` не писать.

Свой новый модуль этими директивами не обвешивать: у него обычные процедуры. Директива нужна, когда перехватывается процедура типового модуля.

`&Перед` и `&После` — поведение вокруг типовой процедуры, тело которой не меняется. Сигнатура совпадает с перехватываемой.

`&ИзменениеИКонтроль` — когда без правки тела нельзя. Процедура экспортная. Тело скопировано из модуля той базы, которую расширяешь, а не из другой версии. Отличие от типового текста только `#Вставка` / `#КонецВставки` и `#Удаление` / `#КонецУдаления`. Соседние строки не переписывать и не переставлять.

```bsl
&НаСервере
&После("ПередЗаписью")
Процедура дп_ПередЗаписью(Отказ, РежимЗаписи, РежимПроведения)
КонецПроцедуры
```

Директива контекста стоит перед директивой расширения. Имя в кавычках — имя типовой процедуры.
