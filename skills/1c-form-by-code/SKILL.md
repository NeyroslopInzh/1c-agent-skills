# Реквизиты на форму только кодом

Своё поле, реквизит формы, команда и событие появляются из модуля. В `Form.xml` их не добавляют и макет ради них не правят. Пустая заимствованная форма — скилл `1c-extension-forms`. Этот скилл его не заменяет.

Реквизит объекта лежит в метаданных. На форму его выводит `&После("ПриСозданииНаСервере")` в области `ОбработчикиСобытийФормы`:

```bsl
&НаСервере
&После("ПриСозданииНаСервере")
Процедура дп_ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

	Поле = Элементы.Добавить("дп_ИмяПоля", Тип("ПолеФормы"), Элементы.ГруппаРодителя);
	Поле.Вид = ВидПоляФормы.ПолеВвода;
	Поле.ПутьКДанным = "Объект.дп_ИмяРеквизита";
	Поле.Заголовок = НСтр("ru = 'Заголовок'");

КонецПроцедуры
```

Родитель — группа, которая уже есть на типовой форме. Чтобы встать перед конкретным элементом, вызывай `Элементы.Вставить` и передай этот элемент.

Обработчик поля — процедура модуля в области обработчиков этого элемента. Имя процедуры передай в `Поле.УстановитьДействие`. В `Form.xml` событие не пиши.

Реквизит самой формы, не объекта, добавляй через `ИзменитьРеквизиты`. Блок `Attributes` в `Form.xml` не заполняй.
