# Пустая форма в расширении

Эталон — форма, заимствованная в конфигураторе, на которую ничего не добавляли. Замеры такой выгрузки для справочника `Номенклатура`, формы `ФормаЭлемента`: [reference.md](reference.md).

«Пустая» здесь значит: форму заимствовали и в конфигураторе ничего на неё не добавляли. Это не пустой `AutoCommandBar` и не копия `Form.xml` из CF.

Дерево элементов (`ChildItems`) типовой формы в выгрузке есть. Так и заимствовать: дерево не вырезать и не считать ошибкой. Дерево реквизитов формы тоже остаётся как в выгрузке. Эти реквизиты не заимствованные и не добавленные: блок `<Attributes/>` пустой, своих полей в `Form.xml` нет, реквизиты родителя в расширение не заимствуются.

## Что лежит в эталоне

Родитель (`Catalogs/Номенклатура.xml`):

- `ObjectBelonging` = `Adopted`, `ExtendedConfigurationObject` = uuid объекта в CF
- `GeneratedType` скопированы из CF (свои TypeId не выдумывать)
- в `ChildObjects` только `<Form>ФормаЭлемента</Form>`
- нет заимствованных реквизитов, табличных частей и команд

Мета формы (`Forms/ФормаЭлемента.xml`):

- новый uuid формы в расширении
- `PropertyState`: `Form` = `Extended`
- `ObjectBelonging` = `Adopted`, `FormType` = `Managed`
- `ExtendedConfigurationObject` = uuid этой формы в CF

`Ext/Form.xml` эталона (6895 строк):

- дерево элементов типовой формы есть
- `DataPath`, `RowPictureDataPath`, `Events`, `Commands`, `CommandSet`, `CommandInterface`: **0**
- реквизитов формы нет: пустой тег `<Attributes/>`, не копия блока из CF
- сразу после него `<BaseForm version="2.20">` — вторая копия того же дерева и снова `<Attributes/>`. Без `BaseForm` конфигуратор считает макет своим и тащит его в дерево расширения
- все `CommandName` равны `0` (в эталоне их 86, во внешнем дереве; столько же внутри `BaseForm`)
- `CommonPicture.*` нет; чужие картинки записаны как `0:uuid`, `StdPicture` остаётся
- модуля нет, пока в форму не пишут код

## Как добавлять форму

1. В конфигураторе заимствовать объект **без** его реквизитов и команд.
2. Заимствовать нужную форму. Макет не менять, свои поля на форму не класть.
3. Выгрузить расширение в XML / cfe. `Ext/Form.xml` взять из этой выгрузки.
4. Поведение и свои элементы — только `Ext/Form/Module.bsl`: `&После` / `&ИзменениеИКонтроль`, элементы через `Элементы.Добавить` в `&После("ПриСозданииНаСервере")`. `Form.xml` после выгрузки не править.
5. Собственные формы новых объектов `дп_*` этим скиллом не собираются: у них обычная Own-форма.

Пока конфигуратора нет, кандидат в `Ext/Form.xml` годен только если он проходит проверку ниже для **этой же** формы. Чужое дерево (другой объект, другая форма) подставлять нельзя.

## Проверка перед import

- [ ] Мета: Adopted + новый uuid + ECO формы CF + `PropertyState Form=Extended`
- [ ] Родитель: Adopted + ECO объекта + типы из CF + только `<Form>Имя</Form>`
- [ ] В родителе нет новых Adopted-реквизитов, ТЧ и команд
- [ ] В `Ext/Form.xml` дерево `ChildItems` типовой формы на месте. Его не вычищать
- [ ] `DataPath` = 0, `Events` = 0, `Commands` = 0, `CommandSet` = 0. Реквизиты формы не заимствованы и не добавлены: только пустой `<Attributes/>`
- [ ] Есть `<BaseForm>` с тем же деревом и своим `<Attributes/>`. Внешнее дерево и `BaseForm` совпадают
- [ ] Каждый `CommandName` равен `0`
- [ ] Свои поля в `Form.xml` не добавлялись; они в модуле
- [ ] `ConfigDumpInfo.xml` расширения не подмешан к полной загрузке, если импорт идёт каталогом целиком

Если ibcmd ругается на путь, команду или картинку — остановиться. Не заимствовать реквизиты родителя и не наращивать метаданные, чтобы заткнуть ошибку.

## Запрещено

- Копировать CF `Ext/Form.xml` в расширение как есть
- Считать пустым файлом один `<AutoCommandBar name="ФормаКоманднаяПанель" id="-1"/>` — эталон так не устроен
- Рисовать свои поля, события и команды в `Form.xml`
- Заимствовать реквизиты, табличные части и команды родителя «потому что форма на них ссылается»
- Подменять `Form.xml` формой другого объекта
- Метки vcoder в модуле

## Свой элемент в модуле

```bsl
&НаСервере
&После("ПриСозданииНаСервере")
Процедура дп_ПриСозданииНаСервере(Отказ, СтандартнаяОбработка)

	Поле = Элементы.Добавить("дп_ИмяПоля", Тип("ПолеФормы"), Элементы.ГруппаРодителя);
	Поле.Вид = ВидПоляФормы.ПолеФлажка;
	Поле.ПутьКДанным = "Объект.дп_ИмяРеквизита";
	Поле.Заголовок = НСтр("ru = 'Заголовок'");

КонецПроцедуры
```

Реквизит `дп_ИмяРеквизита` — own-реквизит объекта в расширении, не заимствованный реквизит CF. Группа `ГруппаРодителя` должна уже быть в типовой форме.
