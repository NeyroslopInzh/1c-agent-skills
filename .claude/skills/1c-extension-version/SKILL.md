# Версия расширения

Свойство то же, что у конфигурации: `Версия`, в XML `<Version>` внутри `Properties` файла `Configuration.xml`. Формат, который сравнивает БСП в этой линейке (`ОбщегоНазначенияКлиентСервер.СравнитьВерсии`): четыре числа через точку, `РР.ПП.ЗЗ.СС`.

- `РР` — редакция
- `ПП` — подредакция
- `ЗЗ` — релиз
- `СС` — сборка

Пустая версия для сравнения равна `0.0.0.0`. Этот номер не ставить: в обновлении информационной базы он значит «версии нет».

Новое расширение сразу получает `<Version>0.0.0.1</Version>`. Это самая маленькая версия после пустой. Релизом её не считать.

После каждого изменения расширения сборка увеличивается на 1: `0.0.0.2`, `0.0.0.3`. Редакция, подредакция и релиз при этом не меняются. Одно изменение — один шаг, даже если правятся несколько файлов.

Третье число увеличивается только когда пользователь говорит о релизе. Сборка после этого снова `1`: было `0.0.0.14`, после слова «релиз» становится `0.0.1.1`.
