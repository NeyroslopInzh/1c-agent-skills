# Константы расширения

Отдельной формы на каждую тему нет. Все константы расширения редактируются на одной общей форме `дп_НастройкиРаботыРасширения`, синоним «Настройки работы расширения».

Форма своя. Поля, группы и команда записи создаются в модуле, в `ПриСозданииНаСервере`. В `Form.xml` своих полей нет.

Константы одной области лежат в одной обычной группе с заголовком. Заголовок группы — имя области, не имя константы. Сейчас печать чека — группа «Печать чека». Новая константа другой области получает свою группу с заголовком. Булево — флажок.

Форма входит в заимствованную подсистему `Администрирование`. Это группа «Администрирование» раздела «НСИ и администрирование», рядом с обслуживанием. Uuid родителя бери из выгрузки этой базы. В УТ 11.6 этой линейки он `2334b788-c741-4750-ad17-c7f2ca4eb794`. Своей подсистемы под константы не заводить. Основной роли расширения права на заимствованную подсистему не давать: платформа это запрещает. `View` на саму форму в роли есть.
